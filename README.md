# Quick Moving Leads Netlify Site

This is a static lead-generation site for `quickmovingleads.com`.

## Deploy on Netlify

1. Create a new Netlify site.
2. Upload this folder or connect it to a Git repository.
3. Set the publish directory to the site root.
4. Add the domain `quickmovingleads.com`.
5. In Netlify Forms, open the `lead-availability` form and add an email notification to `quickmovingleads@gmail.com`.

## Important pages

- `/exclusive-moving-leads/` targets the main SEO keyword.
- `/shared-moving-leads/` supports shared lead buyers.
- `/exclusive-vs-shared-moving-leads/` compares both offers.
- `/contact/` contains the primary lead form.
